Candidate frozen design to finalize BEFORE model predictions are examined:
1. All video-only RAVDESS speech clips. No audio, song, new annotation or training.
   No outcome-dependent actor, category or clip selection. Hash each archive and
   extracted file. Verify filenames, decoded duration/frame counts and inspect
   uniformly sampled quality-control frames without reference to model scores.
2. Primary prediction unit is a complete clip. Sample eight equispaced temporal
   bin centers over its decoded duration; do not choose expression peaks. Run
   the same frozen MediaPipe face detector/crop policy for every model. Preserve
   detector version/weights/hash, bounding boxes and per-frame failure flags.
   Freeze the exact crop expansion and multi-face rule from audited app code.
   No outcome-based detector tuning. Require >=4 valid face frames per clip;
   otherwise abstain and report the failure count, never discard silently.
3. Apply the original grayscale3/224-bilinear/0.5 transform. Aggregate frame
   probabilities by arithmetic mean over valid frames, then choose argmax.
   This is a new clip aggregation rule, not a retrospectively claimed property
   of the current prototype or a trained temporal recognizer.
4. Evaluate Soft, Uniform and Tie-Uniform for both families, all three seeds,
   both selected and fixed-epoch states: 36 inference states, zero new fits.
   Primary score remains MSP. Margin/negative entropy reported as sensitivities.
   At 80% coverage of all clips, choose ceil(.8*N) highest-scoring valid clips;
   if fewer valid clips exist, report the endpoint unavailable, and actual
   maximum coverage. Detector failures are never assigned an invented category.
   Other 20/50/100% points must label unavailable coverage explicitly. Per-clip
   probability, frame count, status and file hash are retained for all clips.
5. First report full nine-category categorical-response disagreement, retaining
   calm and none separately as unsupported responses. MANDATORY reference

   ignoring that rule. Keep none separate in both conventions; no renormalizing

6. Report both control contrasts, all paired seed values, own-ranking/fixed-set

7. Check exact/near image overlap against original FER image hashes before

8. All results, including adverse/null/unavailable cases, must be retained. Do
